High availability:
{{- if eq (include "forklift.postgres" .) "true" }}
  Leader election via Lease "{{ include "forklift.leaseName" . }}" only picks the pod that runs background jobs.
{{- else if .Values.replication.enabled }}
  PV-BASED REPLICATION is ENABLED ({{ include "forklift.replicaCount" . }} replicas, StatefulSet, per-pod RWO PVC).
  The standby pulls the leader's data every {{ .Values.replication.interval }}; writes within
  one interval can be lost on failover. Traffic follows the forklift.io/role=leader pod label.
{{- else if eq (include "forklift.haEnabled" .) "true" }}
  HA is ENABLED ({{ include "forklift.replicaCount" . }} replicas, leader election via Lease "{{ include "forklift.leaseName" . }}").
  Ensure persistence.accessModes is ReadWriteMany so all replicas share the volume.
  No RWX storage available? Set replication.enabled=true for per-pod RWO volumes.
{{- else }}
  HA is DISABLED (single instance). Set replicaCount > 1 (and RWX storage, or
  replication.enabled=true for per-pod RWO volumes) for HA.
{{- end }}

Reach the API/UI:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "forklift.fullname" . }} 8080:{{ .Values.service.port }}
  open http://localhost:8080

First admin user: {{ .Values.auth.bootstrap.adminUser }}
{{- if .Values.auth.bootstrap.adminPassword }}

    kubectl -n {{ .Release.Namespace }} get secret {{ include "forklift.fullname" . }} \
      -o jsonpath='{.data.bootstrap-admin-password}' | base64 -d ; echo

Create a repository (admin):
  curl -u {{ .Values.auth.bootstrap.adminUser }}:<password> -X POST http://localhost:8080/api/v1/repositories \
    -H 'Content-Type: application/json' \
    -d '{"name":"maven-central","format":"maven","type":"proxy","upstream_url":"https://repo1.maven.org/maven2"}'
